## GCP Yt Rebalance 0.4.0

Desenvolvido por Bruno Albertini | [Gestão Cultural Pro](https://gestaoculturalpro.com.br)

### 🇧🇷 Novidades
- Interface totalmente redesenhada: painel inicial com atalhos, ícones vetoriais e cartões ilustrados.
- Tema claro, escuro ou do sistema, com troca instantânea.
- Interface em Português, English e Español.
- Atualizações direto no aplicativo: o app verifica o GitHub, baixa o instalador do seu sistema, confere o SHA-256 e instala.
- Nova tela **Apoie o projeto** com PIX (QR Code e copia e cola) e Stripe.
- Novos pacotes: `.rpm` (Fedora, openSUSE, RHEL) e `.pkg.tar.zst` (Arch, Manjaro), além de `.deb`, Windows e macOS (Apple Silicon e Intel).

### 🇺🇸 What's new
- Fully redesigned interface: home dashboard, vector icons and illustrated tool cards.
- Light, dark or system theme with instant switching.
- Interface available in Portuguese, English and Spanish.
- In-app updates: checks GitHub, downloads the installer for your system, verifies SHA-256 and installs it.
- New **Support the project** screen with PIX and Stripe.
- New packages: `.rpm` and `.pkg.tar.zst`, plus `.deb`, Windows and macOS (Apple Silicon and Intel).

### 🇪🇸 Novedades
- Interfaz completamente rediseñada: panel de inicio, íconos vectoriales y tarjetas ilustradas.
- Tema claro, oscuro o del sistema con cambio instantáneo.
- Interfaz en portugués, inglés y español.
- Actualizaciones dentro de la aplicación: consulta GitHub, descarga el instalador de tu sistema, verifica el SHA-256 e instala.
- Nueva pantalla **Apoya el proyecto** con PIX y Stripe.
- Nuevos paquetes: `.rpm` y `.pkg.tar.zst`, además de `.deb`, Windows y macOS (Apple Silicon e Intel).

### Downloads
| Sistema | Arquivo |

| Windows 10/11 (64 bits) | `GCP-Yt-Rebalance-0.4.0-Windows-x64-Setup.exe` |
| macOS Apple Silicon (M1/M2/M3/M4) | `GCP-Yt-Rebalance-0.4.0-macOS-arm64.dmg` |
| macOS Intel | `GCP-Yt-Rebalance-0.4.0-macOS-x86_64.dmg` |
| Ubuntu, Debian, Linux Mint, Pop!_OS | `gcp-yt-rebalance_0.4.0_amd64.deb` |
| Fedora, openSUSE, RHEL | `gcp-yt-rebalance-0.4.0-1.x86_64.rpm` |
| Arch, Manjaro, EndeavourOS | `gcp-yt-rebalance-bin-0.4.0-1-x86_64.pkg.tar.zst` |

Tudo incluído: motor de separação, modelo, FFmpeg/ffprobe, downloader e runtime. Nada para instalar por fora.
Checksums em `SHA256SUMS.txt`.

**macOS:** na primeira abertura, clique com o botão direito no app → **Abrir** (ou Ajustes do Sistema → Privacidade e Segurança → **Abrir mesmo assim**).
**Windows:** se o SmartScreen aparecer, clique em **Mais informações → Executar assim mesmo**.
